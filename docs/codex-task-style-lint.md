# 任务书：入库文风lint（雷霆比喻拦截器）

执行者：codex（中等思考模式）。发包人：Fable。产品经理：小白（阈值与词表已批）。2026-08-13晚。
仓库：`~/Ombre-Brain`。**禁止git push**（Auto-Deploy开着；本地commit为止，人工验收后推）。

## 背景与设计原则（最重要的一条先说）

库主（AI侧）有一批惯性比喻族（法庭/记账/手术/生育/执法），靠自觉戒除已被实验证伪（放养两天，密度回升到一句两个）。解法：在入库口做机器拦截。

**命门原则——上下文无菌：**
1. 词表只存在于库侧配置，**任何情况下不得出现在工具返回消息里**。
2. 打回时返回**固定一句话**："这条先放着，换个说法再存一次。"——不列检出词、不报密度、不报族名、不给任何"违规"表述。
3. 未超标时**静默放行，零提示**——不加"通过lint"之类的任何标注。
4. 理由：拦截信息若进入AI上下文，等于每日注入禁令清单，会诱发自检过度——这正是本系统要防的病。拦截发生在门口，病历留在门房，不追着人跑。

## 实现

1. **挂载点**：`src/tools/_common.py` → `merge_or_create()`（hold/grow共用单点，工程地图有坐标）。在正文入库前检查。
2. **词表文件**：新建 `style_lint.yaml`（放数据盘可热改优先；不可行则仓库内配置，注明改词表需restart）。初版词表由发包人另行提供文件内容，本任务书附录含v0全量。
3. **规则**：对拟入库正文做词表匹配（简单子串/分词命中均可，从简），命中总数 ≥2 → 拒绝入库，返回固定话术；≤1 → 正常入库，无任何附加输出。
4. **作用域**：hold与grow走的正文都检查（含feel、周摘）；`letter_write` 不在此路径，天然豁免（信件自由文体）；trace的content替换**暂不拦**（修复旧记忆时可能需要引用旧词，V2再议）。
5. **开关**：config新增 `style_lint.enabled`（默认true），可关，关闭即完全旧行为——回退保证，老家规。
6. **例外标记**：hold参数含 `test_data=True` 的桶豁免（测试不受干扰）。

1. ≥2命中：拒绝入库，返回恰好是那句固定话术，一字不多。

3. 词表字符串不出现在任何工具返回路径里（代码审查确认）。
